# Security

Do not post credentials or customer data in public issues. Use GitHub's private
vulnerability reporting when enabled for this repository. Otherwise report a
minimal non-sensitive description and ask for a private channel.

This is a prompt-driven workflow kit. Hash pins detect drift from a saved plan;
they do not authenticate a malicious repository or enforce tool permissions.
Inspect code and prompts before setup. Connector permissions and the host's
approval policy remain authoritative. A clone has no activation hook.
